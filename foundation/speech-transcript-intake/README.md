# 録音を文字に起こして、その文字をエージェントに読ませるとき

**この手引きはこの環境で実測していません。** 文字起こしを一度も回しておらず、特定のモデル・
実行基盤の導入を勧めるものではありません。状態は `experiment` です。公式の記述から引いた内容は
確認した時点のもので、版が上がれば変わります。

## 何の問題を扱うか

起動条件は、**会議や通話の録音を機械で文字に起こし、その文字をエージェントに読ませると
決めたとき**です。要約させる、議事録にする、課題を拾わせる、決まったことを抽出させる、
いずれも含みます。

隣接する手引きとの違いは、**入力そのものが生成物である**という一点です。

| 手引き | 問い |
| --- | --- |
| [../local-model-boundary/](../local-model-boundary/) | その資料を外へ出さないために、どの部品を手元に置くか |
| [../comprehension-debt/](../comprehension-debt/) | 書かせた量が増えたとき、人の理解をどう保つか |
| [../agent-report-handoff/](../agent-report-handoff/) | エージェントが出した結論を、人がどう受け取るか |
| ここ | **渡した「元資料」が、そもそも誰かの発言の写しなのか** |

文書を渡すときは、原本が先にあります。文字起こしでは逆で、**原本（音声）から機械が書き起こした
テキストが渡されます。** ここを同じ扱いにすると、以下すべてが見えなくなります。

## 誤りの形が、「聞き落とし」ではない

最も重要な事実はこれです。文字起こしの誤りは、**抜ける**のではなく**足される**形で出ます。

査読を経た調査（`REF-245`）は、ある広く使われた文字起こしモデルについて、
**音声にまったく存在しない句や文が、書き起こし全体のおよそ 1 % に現れた**と報告しています。
さらにその幻覚のうち **38 % が明示的な害を含み**、著者は 3 つに分類しています。
暴力の永続化、不正確な関連付けの作成、**虚偽の権威づけ**です。

そして分布が一様ではありません。**沈黙や単語間の間（ま）が長い話者で多く出ます。** 調査の対象は
失語症のある話者と無い話者の音声で、前者で幻覚がより多く観測されました。

> 会議の録音は、沈黙・言い淀み・かぶり・保留音の塊です。この調査が幻覚の引き金として
> 名指しした条件は、議事録の素材そのものに当てはまります。

ここから出る運用上の結論は 1 つです。**文字起こしの一文を「誰かがそう言った」として扱わない。**
要約させても、その要約は存在しない文から作られている可能性があります。

### 提供元自身も、同じ場所に注意を置いている

この入力で調べたモデルの公式の案内（`REF-242`）は、出力について
**名前・話者の切り替わり・質問への答えを抜き取り確認するよう**書いています。
モデルカード（`REF-241`）が備える幻覚対策は、**同じ文字が 21 回以上続いたら 1 つに畳む**という
後処理の関数です。これは**暴走の繰り返しを止めるもの**であって、
もっともらしい 1 文が足される側には効きません。

## 誤り率を根拠にすると、この失敗はちょうど見えない

「誤り率が低いモデルを選べばよい」は、ここでは成立しません。

査読を経た分析（`REF-246`）は 20 を超える文字起こしモデルを対象に、幻覚を測る指標を別に立て、
次の向きを報告しています。**高い誤り率が低い幻覚率を覆い隠す一方、低い誤り率は危険な幻覚を
覆い隠しうる。** 学習時と入力の分布のずれと幻覚の強い相関（相関係数 0.91）も報告され、
合成した雑音を足すと幻覚が増えることも確かめられています。

裏取りとして評価の仕組み側（`REF-244`）を見ると、公開の順位表が持つのは誤り率と処理速度で、
**幻覚を測る指標はありません。** 参照文への過剰適合を測る仕組みは別に用意されています。

つまり、順位表の数字は「どれだけ取りこぼさないか」の指標であって、
**「無いことを書かないか」の指標ではありません。** 用途が議事録なら、後者が効きます。

### 1 つの数字で語らない

同じモデルについて、提供元が同じ時期に出した英語の誤り率が 2 つあります。
公式の案内（`REF-242`）は公開の順位表で **5.33 %**、モデルカード（`REF-241`）は同じ順位表の
9 データセット平均として **4.71 %** です。集計の対象が違うとしか読めず、どちらかが誤りだとは
扱いません。使うのは**用途に近い行を見る**という向きだけです。同じモデルカードで、
**長い音声は 10.98 %、複数話者は 15.80 %**（話者の取り違えを含む誤り率）と、
桁が変わります。会議の録音は後ろ 2 つに当たります。

評価の実行条件（機材、容器、データセットの組）は評価の仕組み側（`REF-244`）にあり、
提供元の内部評価とは別の手順です。**自分の音声での値ではない**ことは、どちらにも共通します。

## 専門語に合わせると、一般の精度は下がる

公式の案内（`REF-242`）が載せた医療分野への適応の例は、この取引をそのまま数字で示しています。
対象領域の誤り率は **30.8 % → 23.8 %（指示文の調整）→ 11.8 %（追加学習）** と下がる一方、
一般的な英語の読み上げでの誤り率は **1.54 % → 1.69 %** へ上がりました。

社内の用語・製品名・人名に合わせ込むと、合わせ込んでいない部分は悪くなります。
**片方だけを測って導入を決めない**、という条件が要ります。

## 手当てはできる。ただし消えない（反対の向き）

この向きに対する反証も登録しました（`REF-247`）。幻覚そのものを学習側で狙って減らす試みで、
**無音の区間で語が出る割合は 61.9 % から 2.4 % へ**下がっています。方向としては改善です。

ただし同じ報告で、**声の入っていない実際の音声では 99.9 % から 47.8 % までしか下がっていません。**
著者自身も、非音声を学習させると本来の音声検出の性能が落ちうると書いています。
**査読の記載が無い単著の報告**なので、採ったのは「手当てはできるが残る」という向きだけです。

> 「対策済み」と書かれたモデルに替えることは、この節の手順を省く理由になりません。

## 置き場所の判断は別の手引き、ただし 1 つ足す

音声を外へ出せるかどうかの判断は [../local-model-boundary/](../local-model-boundary/) の
3 つの要件（学習に使われない／保持されない／そもそも外へ出ない）で決めます。
ここで足すのは次の 1 点です。

**手元で文字起こししても、出てきた文字が音声の中身だとは限りません。**
置き場所の制約が満たされたことと、入力が信用できることは別の問題です。

手元で動かす選択肢が現実に在ることは、この入力の入口（`ART-060`）とモデルカード（`REF-241`）で
確かめました。重みは公開され、日本語は対応段階の中位（実用可）に置かれ、
推奨される機材は単一の大型 GPU です。**この環境には該当する機材がありません。**

### ライセンスは「無償」だけで読まない

このモデルの配布条件（`REF-243`）は、商用・非商用のいずれにも使えると書かれていますが、
条文には 3 つ条件が付きます。

1. 配布するときは、**ライセンスの写しと著作権・出所の表示を保持する**。
2. 対象について**特許または著作権の侵害を主張する訴えを起こすと、付与された権利が終了する**
   （先に相手から同種の訴えを受けた場合を除く）。
3. **いかなる保証も無く、提供者は損害について責任を負わない。**

対象は重みだけでなく、関連するデータ・文書・ソフトウェアを含みます。
業務で使う前に、条文を自分の立場で読み直します。

## 確かめる手順（charter）

- **用途**: 機械の文字起こしをエージェントの入力にしてよいか、してよい範囲はどこまでかを、
  推測ではなく自分の録音で確かめる。
- **入力**: 自分の用途に近い録音を少数（沈黙・保留音・かぶりを含むものを必ず 1 本）、
  その録音の正解となる書き起こし（少数の区間でよい）、使う文字起こしの構成。
- **安全境界**: 確認作業そのもので録音や書き起こしを外へ出さない。外部の問い合わせに
  本文を貼らない。比較の記録に発言内容を残さない。
- **検証方法**:
  1. **録音を捨てない**。文字だけ残した時点で、以降どの主張も検証できなくなる。
  2. 沈黙・保留音・雑音だけの区間を含む録音を 1 本通し、**その区間に何が出力されたか**を見る。
     何も出ないことを確かめるまでは、無人で回さない。
  3. 用途に近い条件（長い音声、複数話者）で、正解と突き合わせる。公開の順位表の値を
     自分の値として使わない。
  4. エージェントへ渡すときは、**これが機械の生成物で、音声に無い文が混じりうることを
     入力に明示**し、引用には時刻を付けさせる。時刻が無い引用は裏が取れない。
  5. 固有名詞・数値・発言の帰属は、文字起こしから引用する前に**音声で当たる**。
     提供元自身が抜き取り確認を求めている箇所（`REF-242`）と同じ 3 種類である。
  6. 社内の用語に合わせ込む構成を入れるなら、**合わせ込んでいない範囲も同時に測る**。
- **終了条件**: 2 と 5 が通り、エージェントに渡してよい範囲（例: 要約はよい、引用は不可）が
  書けたら終わり。2 で何か出力されるなら、その構成は無人の経路に乗せない。

## 限界

- **この環境では一度も文字起こしを回していません。** 上の手順は未実行で、手順自体の有効性も
  確かめていません。機材の要件も満たしていません。
- **`REF-245`・`REF-246`・`REF-247` はいずれも要旨の範囲でしか確認していません。** 本文の
  手法・標本・統計処理は読めていないので、採ったのは割合と向きだけです。発表元の PDF は
  取得できませんでした。
- `REF-245` の対象は**特定の 1 モデルと、英語の、失語症を含む音声コーパス**です。
  日本語での発生率も、`REF-241` のモデルでの発生率も**誰も測っていません**。
  採ったのは「誤りが追加の形で出る」「間の長さが引き金になる」という機構だけです。
- `REF-247` は**査読の記載が無い単著の報告**です。数値は 1 つのモデルについてのもので、
  他の言語・他のモデルへの一般化は書かれていません。
- `REF-241`・`REF-242` は**提供元自身の評価**です。順位も誤り率も再現していません。
  技術報告書は PDF が開けず、**学習データの内訳と量子化版の精度差は未確認**です。
- 公表された誤り率の 2 つの値の食い違いは、**集計対象の違いとしか確認できていません。**
  どちらが正しいかは判定していないため、この 2 つの値は選択の根拠にしません。
- `REF-243` は条文の読みであり、法的な助言ではありません。条文の策定者はページに記載が
  ありませんでした。
- `REF-244` は評価の仕組みであって、モデルの推薦ではありません。順位は提出時点の値です。
- `ART-060` は発表の紹介記事です。主要な数値は一次情報と一致しましたが、
  入口として読むものです。
