# jinjer overlay

この領域は、[foundation/](../../foundation/) をjinjerで利用するときの公開可能な補足です。ここに置く情報は、インターネット上で誰でも読める前提で扱います。

導入時の順序と公開可能な共通原則は [environment-guidance.md](environment-guidance.md) にあります。

## 置いてよいもの

- 汎用設定に追加する、公開可能な開発・レビュー・ドキュメント化の原則
- 社内で使う際の責任分界を説明する抽象的な手順
- 公開済みの外部資料へのリンクと、公開可能な判断

## 置かないもの

- 社内システムのURL、認証方法、トークン、権限設定、顧客・従業員データ
- 実在するプロジェクト名、実行環境、業務数値、未公開の戦略・運用
- 個人の端末パス、許可済みコマンド、会話履歴、バックアップ

社外秘の補足が必要な場合は、このリポジトリへ本文を追加せず、アクセス制御された社内文書に保持します。このREADMEにはその存在を示すリンクも載せません。
