# Agent operations

Use this topic when adding an instruction, creating a skill, synchronizing agent setup, or considering multi-agent automation.

- Put durable, universally applicable safety constraints in the smallest possible shared instruction layer.
- Put reusable work with a clear trigger, inputs, and verification in a skill.
- Put rare or detailed material in a reference document and state when it must be read.
- Use the SOP template for operations that can change data or need another person to run them.
- Treat autonomous loops as a measured experiment, not a productivity promise.
- Before synchronizing settings across agent products, apply [ADR-0002](../decisions/ADR-0002_agent_configuration_ssot.md).
