# Presentation formats and reusable assets

Use this topic when making slides, a web presentation, or a reusable UI component.

## Format choice

- For an existing branded or collaboratively edited presentation, preserve the native slide object model, master/theme, and editable elements. Do not regenerate it from Markdown.
- For a code- or math-centric technical talk distributed in a browser, Reveal.js/Markdown is a valid reference option.
- Keep content outline and visual implementation separate. Markdown may be the outline, but it is not automatically the final layout source of truth.

## Asset library

Preserve a reusable UI asset only after visual and functional review. Record its purpose, dependency boundary, source project, and license/brand restriction. Never include unreviewed third-party JavaScript as a reusable asset.
