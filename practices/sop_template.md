# SOP template

Use this structure when a task needs reproducibility, another operator, or a safety boundary.

```markdown
## Purpose and boundary
## Inputs and preconditions
## Operation classification
Read | Create | Update | Delete | Admin

## Preview and approval
## Steps
## Verification
## Rollback
## Evidence to retain
## Known limits and expiry
```

State why every non-obvious prohibition exists. Do not encode generic advice or an implementation-specific command unless the operation requires it.
